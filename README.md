# AI 채찍 (ai-whip)

AI가 말을 안 들을 때, 컴퓨터는 못 부수겠고… 마음속 분노를 폰으로 휘두르는 안드로이드 장난용 앱.

- 고른 앱(예: 피클)이 화면에 떠 있을 때만 동작한다.
- 폰을 세게 흔들면 그 앱 위에 채찍이 휘둘러지고 소리와 진동이 난다.
- 정한 시간(3/5/10/30초, 기본 5초) 동안 휘두르지 않으면 채찍이 접히고 화면 오른쪽 위에 작은 아이콘이 남는다. 아이콘을 누르면 채찍이 돌아온다.
- 설정한 횟수(1/2/3/5번, 기본 3번)만큼 휘둘러 게이지가 다 차면 미리 적어 둔 문구를 그 앱 입력창에 넣는다. 옵션으로 전송 버튼까지 누른다.

특정 AI 서비스와 무관한 개인 제작물이다. Pickle Inc.와 관계없다.

- 소개 페이지: <https://yushinjung.github.io/ai-whip/>
- 설치 안내: <https://yushinjung.github.io/ai-whip/install-guide.html>
- 웹에서 바로 해 보기(그림과 소리만): <https://yushinjung.github.io/ai-whip/try/>

## 동작 방식

| 단계 | 하는 일 | 쓰는 안드로이드 기능 |
|---|---|---|
| 1 | 지금 떠 있는 앱이 혼낼 앱인지 확인 | 접근성 서비스 (`TYPE_WINDOW_STATE_CHANGED`) |
| 2 | 맞으면 가속도 센서를 켬 | `TYPE_LINEAR_ACCELERATION` (없으면 가속도계에서 중력 제거) |
| 3 | 16 m/s² × 감도 배율을 넘으면 타격 | 임계값 비교, 350ms 간격 제한 |
| 4 | 대상 앱 위에 채찍·말풍선·게이지를 그림 | `TYPE_ACCESSIBILITY_OVERLAY` (터치는 통과) |
| 5 | 게이지 100%면 입력창에 문구를 넣음 | `ACTION_SET_TEXT` |
| 6 | (옵션) 전송 버튼을 누름 | 이름에 보내/전송/send가 든 가까운 버튼 클릭, 없으면 `ACTION_IME_ENTER` |

화면이 꺼지거나 다른 앱으로 넘어가면 센서를 끈다.

## 권한과 개인정보

- 인터넷 권한이 없다. 어떤 데이터도 기기 밖으로 나가지 않는다.
- 접근성 서비스는 화면 내용을 읽을 수 있는 강한 권한이다. 이 앱은 입력창과 전송 버튼을 찾는 데만 쓰고, 읽은 내용을 저장하지 않는다. 코드는 `WhipService.kt` 한 파일에서 확인할 수 있다.
- 그 외 권한은 진동 하나뿐이다.

## 설치

처음 설치한다면 설치 안내를 먼저 본다. 경고 화면마다 무엇을 눌러야 하는지 순서대로 적혀 있다.

- 폰에서 따라 하기: <https://yushinjung.github.io/ai-whip/install-guide.html> 를 연다. 단계마다 체크하며 따라 할 수 있다. 같은 파일이 [Releases](../../releases/latest)에도 있다.
- 글로 읽기: [docs/INSTALL.md](docs/INSTALL.md). PC로 설치하는 방법도 여기에 있다.

아래는 요약이다.

### 먼저 알아둘 것: Play 프로텍트 차단

한국에서는 접근성 권한을 쓰는 앱을 브라우저·메신저·파일 관리자로 받아 설치하면 Google Play 프로텍트가 자동으로 차단한다(2025년 9월 도입된 EFP 기능). 이 앱도 해당한다. 악성 판정이 아니라 권한 조합에 따른 규칙이다.

- 권장: PC에서 USB로 설치한다(아래 "USB로 설치").
- Play 프로텍트를 끄고 설치하는 방법도 있지만, 끄는 동안 다른 앱 검사도 멈춘다. 본인 책임으로 하고 설치 후 바로 다시 켠다. 다시 켠 뒤 이 앱에 경고가 뜨는지는 확인하지 못했다.

### USB로 설치

1. PC에 [Android platform-tools](https://developer.android.com/tools/releases/platform-tools)를 받아 압축을 푼다.
2. 폰에서 설정 → 휴대전화 정보 → 소프트웨어 정보 → 빌드번호를 7번 눌러 개발자 옵션을 켠다.
3. 설정 → 개발자 옵션 → USB 디버깅을 켠다.
4. 폰을 USB로 연결하고, 폰에 뜨는 "USB 디버깅을 허용하시겠습니까?"에서 허용을 누른다.
5. PC 터미널에서 실행한다.

```bash
adb install ai-whip.apk
```

### 설치 후 설정

1. 앱을 열고 **접근성 설정 열기**를 누른다.
2. **설치된 앱**(기기에 따라 "다운로드한 앱")을 누른다.
3. **AI 채찍**을 누른다.
4. 맨 위의 **꺼짐** 스위치를 켠다. "AI 채찍 바로가기"는 켜지 않아도 된다.
5. 안내 창에서 **허용**을 누르고 앱으로 돌아온다. 상태가 "켜짐 — 준비 완료"로 바뀐다.
6. 스위치가 회색이거나 "제한된 설정" 안내가 뜨면: 앱의 **앱 정보 열기** → 오른쪽 위 ⋮ → **제한된 설정 허용**을 누른 뒤 1번부터 다시 한다. 안드로이드 13 이상에서 스토어 밖 앱에 걸리는 제한이다.
7. **혼낼 앱**을 고른다.
8. 보낼 문구를 확인한다. 처음에는 "전송 버튼까지 자동으로 누르기"를 끄고 문구가 입력창에 들어가는지만 본다.
9. **채찍 테스트**로 채찍과 소리가 나오는지 확인한다.
10. 혼낼 앱을 열고 폰을 휘두른다.

메뉴 이름은 삼성 기기 기준이며 제조사에 따라 다를 수 있다.

## 빌드

GitHub Actions가 `main`에 push할 때마다 APK를 만든다(`.github/workflows/build.yml`).
`v0.1.0`처럼 `v`로 시작하는 태그를 push하면 Releases에 APK가 올라간다.

로컬 빌드: JDK 17 이상, Android SDK(platform 35), Gradle 8.14.3.

```bash
gradle :app:assembleRelease
# 결과: app/build/outputs/apk/release/app-release.apk
# KEYSTORE_FILE, KEYSTORE_PASSWORD 환경 변수가 없으면 디버그 키로 서명한다.
```

## 확인된 것과 확인되지 않은 것

| 항목 | 상태 |
|---|---|
| APK 빌드 | 확인됨 (Gradle 8.14.3, AGP 8.7.3, Kotlin 2.0.21, JDK 21) |
| 실제 폰에서 채찍이 그려지는지 | 미확인 |
| 대상 앱이 떠 있는 동안 흔들기 감지가 계속 되는지 | 미확인 |
| 피클 입력창에 문구가 들어가는지 | 미확인. 피클 화면이 접근성 정보를 제공하지 않으면 클립보드 복사로 대체된다 |
| 전송 버튼을 찾는지 | 미확인. 못 찾으면 문구만 넣고 안내를 띄운다 |

## 알려진 제한

- v0.1.6부터 고정 키로 서명한다. v0.1.5 이하에서 올릴 때는 기존 앱을 한 번 지우고 설치해야 한다. 그 뒤로는 덮어 설치하면 된다.
- 접근성 권한을 다른 앱 조작에 쓰기 때문에 플레이스토어 등록은 어렵다.
- 대상 앱의 약관이 자동 입력을 금지할 수 있다. 쓰기 전에 확인한다.
- 흔들 때 주변 사람과 폰 낙하에 주의한다.
