# AI 채찍 설치 가이드

이 문서는 AI 채찍을 처음 설치하는 사람을 위한 안내서다.
폰에서 단계마다 체크하며 따라 하려면 Releases의 `install-guide.html`을 받아 연다. 내용은 같다.
설치는 약 5분이 걸린다.

AI 채찍은 Play 스토어에 없는 앱이다.
그래서 설치할 때 안드로이드가 경고를 3번 띄운다.
이 문서는 각 경고가 무엇이고, 어떻게 넘어가는지 순서대로 설명한다.

## 전체 순서

| 단계 | 할 일 | 이유 |
|---|---|---|
| 1 | APK 파일을 받는다 | 스토어에 없는 앱이라 파일로 받는다 |
| 2 | Play 프로텍트를 끈다 | 켜져 있으면 설치가 차단된다 |
| 3 | APK를 설치한다 | "출처를 알 수 없는 앱" 허용이 필요하다 |
| 4 | Play 프로텍트를 다시 켠다 | 다른 앱 검사를 계속 받기 위해서다 |
| 5 | 접근성 서비스를 켠다 | 앱이 동작하려면 이 권한이 필요하다 |
| 6 | 혼낼 앱을 고르고 테스트한다 | |

PC가 있으면 2단계와 4단계를 건너뛸 수 있다. 문서 끝의 "PC로 설치하기"를 본다.

## 설치 전에 읽을 것

### 왜 경고가 뜨는가

AI 채찍은 접근성 권한을 쓴다.
접근성 권한은 화면 내용을 읽고 다른 앱을 대신 조작할 수 있는 강한 권한이다.
금융 사기 앱이 이 권한을 자주 악용한다.
그래서 한국에서는 스토어 밖에서 받은 앱이 이 권한을 쓰면 Play 프로텍트가 설치를 자동으로 차단한다.
차단 기준은 권한의 종류다. 앱이 악성으로 판정된 것은 아니다.

### 이 앱이 하는 일과 하지 않는 일

| 구분 | 내용 |
|---|---|
| 한다 | 혼낼 앱이 화면에 떠 있는지 확인한다 |
| 한다 | 혼낼 앱 위에 채찍 그림을 그린다 |
| 한다 | 혼낼 앱의 입력창에 정해 둔 문구를 넣는다 |
| 하지 않는다 | 인터넷에 연결하지 않는다. 앱에 인터넷 권한이 없다 |
| 하지 않는다 | 화면 내용을 저장하지 않는다 |
| 하지 않는다 | 혼낼 앱이 아닌 다른 앱에서는 동작하지 않는다 |

설치 후 설정 → 애플리케이션 → AI 채찍 → 권한에서 인터넷 권한이 없는 것을 직접 확인할 수 있다.
소스 코드는 모두 공개되어 있다. 접근성 권한을 쓰는 코드는 `WhipService.kt` 한 파일이다.

### 주의

- 이 문서의 절차는 이 앱에만 쓴다. 문자나 메신저로 받은 다른 앱에 같은 절차를 쓰면 안 된다. 금융 사기범이 피해자에게 요구하는 절차와 같기 때문이다.
- APK는 이 저장소의 Releases에서만 받는다. 다른 곳에서 받은 파일은 설치하지 않는다.
- 4단계(Play 프로텍트 다시 켜기)를 건너뛰지 않는다.

## 1단계. APK 파일 받기

1. 폰의 브라우저에서 <https://github.com/YushinJung/ai-whip/releases> 를 연다.
2. 가장 위에 있는 버전에서 `ai-whip.apk`를 누른다.
3. 브라우저가 "유해할 수 있는 파일"이라고 물으면 "무시하고 다운로드"를 누른다.

## 2단계. Play 프로텍트 끄기

1. Play 스토어 앱을 연다.
2. 오른쪽 위의 프로필 아이콘을 누른다.
3. "Play 프로텍트"를 누른다.
4. 오른쪽 위의 톱니바퀴 아이콘을 누른다.
5. "Play 프로텍트로 앱 검사"를 끈다.
6. 확인 창에서 "사용 중지"를 누른다.

## 3단계. APK 설치하기

1. 받은 `ai-whip.apk` 파일을 연다. 브라우저의 다운로드 목록이나 "내 파일" 앱의 Download 폴더에 있다.
2. "이 출처의 앱을 설치할 수 없습니다" 안내가 뜨면 "설정"을 누른다.
3. "이 출처 허용"을 켠다.
4. 뒤로 가기를 누른다.
5. "설치"를 누른다.
6. 설치가 끝나면 "완료"를 누른다. 아직 "열기"를 누르지 않는다.

삼성 폰에서 "보안 위험 자동 차단" 안내가 뜨고 설치가 막히면 다음을 한다.

1. 설정 → 보안 및 개인정보 보호 → 보안 위험 자동 차단을 연다.
2. 스위치를 끈다.
3. 이 단계의 1번부터 다시 한다.
4. 설치가 끝나면 스위치를 다시 켠다.

## 4단계. Play 프로텍트 다시 켜기

1. Play 스토어 앱을 연다.
2. 오른쪽 위의 프로필 아이콘을 누른다.
3. "Play 프로텍트"를 누른다.
4. 오른쪽 위의 톱니바퀴 아이콘을 누른다.
5. "Play 프로텍트로 앱 검사"를 켠다.

다시 켠 뒤 Play 프로텍트가 AI 채찍에 경고를 띄울 수 있다.
경고가 뜨면 "앱 유지"를 고르면 계속 쓸 수 있다.
경고가 실제로 뜨는지는 확인하지 못했다.

## 5단계. 접근성 서비스 켜기

안드로이드 13 이상은 스토어 밖에서 받은 앱의 접근성 스위치를 막아 둔다.
그래서 제한을 먼저 풀고, 그다음에 스위치를 켠다.

먼저 제한을 푼다.

1. AI 채찍 앱을 연다.
2. "앱 정보 열기 (제한된 설정 허용)"를 누른다.
3. 오른쪽 위의 ⋮(더보기)를 누른다.
4. "제한된 설정 허용"을 누른다.
5. 잠금 화면 비밀번호나 지문을 입력한다.
6. 뒤로 가기를 눌러 AI 채찍 앱으로 돌아온다.

⋮(더보기)가 보이지 않으면 아래 "스위치를 켠다"를 먼저 한 번 한다.
스위치를 누르면 "제한된 설정" 안내 창이 뜬다. 그 뒤에 ⋮가 나타난다.

그다음 스위치를 켠다.

1. AI 채찍 앱에서 "접근성 설정 열기"를 누른다.
2. "설치된 앱"을 누른다. 기기에 따라 이름이 "다운로드한 앱"이다.
3. "AI 채찍"을 누른다.
4. 맨 위의 "꺼짐" 스위치를 켠다.
5. 안내 창에서 "허용"을 누른다.
6. 뒤로 가기를 눌러 AI 채찍 앱으로 돌아온다.
7. 화면의 상태가 "켜짐 — 준비 완료"인지 확인한다.

같은 화면의 "AI 채찍 바로가기"는 켜지 않는다. 바로가기는 서비스를 빠르게 켜고 끄는 단축 기능이다.

## 6단계. 설정하고 테스트하기

1. AI 채찍 앱에서 "앱 선택"을 누른다.
2. 혼낼 앱을 고른다.
3. 보낼 문구를 확인한다. 원하는 문구로 바꿀 수 있다.
4. "몇 번 휘두르면 보낼지"를 고른다.
5. "전송 버튼까지 자동으로 누르기"를 끈다. 처음에는 문구가 입력창에 들어가는지만 확인한다.
6. "채찍 테스트"를 누른다.
7. 채찍 그림과 "짝" 소리가 나오는지 확인한다.
8. 혼낼 앱을 연다.
9. 화면 아래에 "채찍 준비됨 — 휘두르세요"가 뜨는지 확인한다.
10. 폰을 단단히 쥐고 채찍처럼 세게 휘두른다.
11. 고른 횟수만큼 휘두른 뒤 입력창에 문구가 들어갔는지 확인한다.
12. 문구가 들어가면 AI 채찍 앱에서 "전송 버튼까지 자동으로 누르기"를 켠다.

정한 시간(기본 5초) 동안 휘두르지 않으면 채찍이 사라진다. 화면 오른쪽 위에 작은 아이콘이 남는다. 아이콘을 누르면 채찍이 돌아온다. 시간은 AI 채찍 앱의 "채찍이 접히는 시간"에서 3초, 5초, 10초, 30초 중에 고른다.

폰을 휘두를 때는 주변 사람과의 거리를 1 m 이상 둔다. 폰을 떨어뜨리지 않게 주의한다.

## 막힐 때

| 증상 | 해결 |
|---|---|
| 설치 중 "기기 보호를 위해 앱 차단됨"이 뜬다 | 2단계를 다시 확인한다. "Play 프로텍트로 앱 검사"가 꺼져 있어야 한다 |
| 설치 중 "보안 위험 자동 차단" 안내가 뜬다 | 3단계의 삼성 폰 절차를 따른다 |
| 설치 버튼이 없고 "설정"만 보인다 | "설정"을 누르고 "이 출처 허용"을 켠다 |
| 접근성 스위치가 회색이다 | 5단계의 "먼저 제한을 푼다" 절차를 따른다 |
| 채찍이 사라졌다 | 화면 오른쪽 위의 작은 아이콘을 누른다. 정한 시간(기본 5초) 동안 휘두르지 않으면 채찍이 접힌다. 너무 빨리 접히면 앱에서 시간을 늘린다 |
| "채찍 테스트"를 눌러도 반응이 없다 | AI 채찍 앱의 상태가 "켜짐"인지 확인한다. "꺼짐"이면 5단계를 다시 한다 |
| 혼낼 앱에서 "채찍 준비됨"이 뜨지 않는다 | 혼낼 앱을 올바르게 골랐는지 확인한다. 접근성 서비스를 껐다가 다시 켠다 |
| 세게 휘둘러도 채찍이 나오지 않는다 | 흔들기 감도를 "민감"으로 바꾼다 |
| 살짝 움직여도 채찍이 나온다 | 흔들기 감도를 "둔감"으로 바꾼다 |
| 문구가 입력창에 들어가지 않는다 | 문구는 클립보드에 복사되어 있다. 입력창을 길게 눌러 붙여넣는다 |
| 문구는 들어가는데 전송이 되지 않는다 | 전송 버튼을 직접 누른다. 앱마다 전송 버튼을 찾지 못할 수 있다 |
| 업데이트 후 동작하지 않는다 | 접근성 서비스를 껐다가 다시 켠다 |

## 끄는 방법과 지우는 방법

잠시 끄기:

1. 설정 → 접근성 → 설치된 앱 → AI 채찍을 연다.
2. 스위치를 끈다.

완전히 지우기:

1. 설정 → 애플리케이션 → AI 채찍을 연다.
2. "삭제"를 누른다.

앱을 지우면 접근성 권한도 함께 사라진다.

## PC로 설치하기 (Play 프로텍트를 끄지 않는 방법)

PC에서 USB로 설치하면 2단계와 4단계가 필요 없다.
Play 프로텍트의 자동 차단은 브라우저·메신저·파일 관리자로 받은 앱에 적용된다.
USB 설치는 이 목록에 없다. 다만 USB 설치가 차단을 피하는지는 직접 확인하지 못했다.

1. PC에서 [Android platform-tools](https://developer.android.com/tools/releases/platform-tools)를 받는다.
2. 받은 파일의 압축을 푼다.
3. PC에서 `ai-whip.apk`를 받는다. 압축을 푼 폴더에 넣는다.
4. 폰에서 설정 → 휴대전화 정보 → 소프트웨어 정보를 연다.
5. "빌드번호"를 7번 누른다. 개발자 옵션이 켜진다.
6. 폰에서 설정 → 개발자 옵션 → "USB 디버깅"을 켠다.
7. 폰을 USB 케이블로 PC에 연결한다.
8. 폰에 뜨는 "USB 디버깅을 허용하시겠습니까?"에서 "허용"을 누른다.
9. PC에서 압축을 푼 폴더를 터미널로 연다.
10. 다음 명령을 실행한다.

```bash
adb install ai-whip.apk
```

11. "Success"가 나오면 이 문서의 5단계로 간다.
12. 설치가 끝나면 폰에서 "USB 디버깅"을 끈다.

## 이 문서의 확인 범위

| 항목 | 상태 |
|---|---|
| Play 프로텍트를 끄면 설치된다 | 제작자의 폰 1대에서 확인 |
| 접근성 서비스를 켜면 동작한다 | 제작자의 폰 1대에서 확인 |
| 삼성 "보안 위험 자동 차단" 절차 | 삼성 공식 안내 기준. 직접 확인하지 않음 |
| "제한된 설정 허용" 절차 | 제작자의 폰 1대에서 확인 |
| USB(adb) 설치 | 직접 확인하지 않음 |

메뉴 이름은 삼성 One UI 기준이다. 제조사와 안드로이드 버전에 따라 이름과 위치가 다르다.
